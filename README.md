Neon Tunnel – Animated Background

An immersive, retro-futuristic animated background built using HTML, CSS, and JavaScript. It features a glowing perspective grid, vibrant neon lighting, and a tunnel-like visual effect that creates a cyberpunk and synthwave atmosphere.

Features

-  Animated perspective grid
-  Neon blue and purple glow effects
-  Retro-futuristic synthwave aesthetics
-  Smooth animations and lighting effects
-  Suitable as a background for modern websites
-  Lightweight and built with pure frontend technologies

 Technologies Used

- HTML5 – Structure
- CSS3 – Styling, glow effects, and animations
- JavaScript – Dynamic visual effects and animation logic
